# Jogo da Forca

Jogo da forca em PHP, com sorteio de palavras, controle de letras escolhidas,
seis tentativas, indicação visual dos erros e condições de vitória e derrota.
O estado da partida é mantido na sessão do PHP.

## Como executar

Requer PHP 8.0 ou superior. No terminal, na pasta do projeto, execute:

```bash
php -S localhost:8000
```

Abra [http://localhost:8000](http://localhost:8000) no navegador. Não são
necessárias dependências adicionais.
